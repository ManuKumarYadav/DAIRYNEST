# DairyNest – Dairy Management System

DairyNest is a full-stack dairy management system built using the MERN stack. It provides role-based dashboards and helps manage dairy products, farmers, milk records, inventory, orders, and users.

## 🚀 Live Demo

[View Live Project](https://dairynest-roan.vercel.app)
